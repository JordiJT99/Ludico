# Validation specification

Validation executes in low-cost order: schema/structure, game invariant, safety/blocked terms, exact fingerprints, recent semantic/entity comparison, source/factual checks, difficulty/quality, then optional evaluator review.

Exact duplicates never pass. Semantic duplicates share a type-specific similarity threshold and a configurable lookback (default 180 days for equivalent quiz questions; 30/120 days for common/rare crossword words). Theme selection limits a main theme to two days per week unless an edition is marked special.

Safety rejects offensive or discriminatory language, inappropriate sexual content, graphic violence, self-harm or dangerous instructions, unsafe medical/legal/financial claims, personal data, extremist propaganda and protected copied text. High-risk factual areas (politics, prices, rankings, law and current events) require review or a fresh verification date. Findings carry a code, item ID, evidence summary and policy version.
